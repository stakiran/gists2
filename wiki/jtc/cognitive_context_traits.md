# 認知的コンテキスト特性（CCT）

既存ページ [認知アーキテクチャによる選抜](cognitive_selection.md) は、昇進試験が割り込み耐性を測っているという理論だった。第 3 回走査で、その理論をさらに一段精密にするフレームワークが見つかった。

人間の認知能力を、LLM のコンテキストウィンドウに見立てて四つの軸で測る。

- **Window** —— 一度に保持できる情報量
- **Switching** —— 文脈を切り替える速さ
- **Compress** —— 情報を圧縮して要点にする力
- **Archive** —— 外部に保存し、後から引き出す力

## 多数派の profile

そして、組織の多数派がどこに位置するかの診断がこれである。

> 多くの会社で最も多いタイプであり、口頭コミュニケーションを支えるだけのウィンドウの広さと…マルチタスクの能力…を持っているが、反面、圧縮と倉庫を鍛える機会がなく、貧弱である。それはつまり…読み書きに基づいた深い思考や非同期的なコミュニケーションが行えないことと同義であり、ミーティングと政治がほぼ必然的に生じることとなる。

**Window 中、Switching 中、Compress 低、Archive 低。** これが多数派の profile であり、この profile からは必然的に会議と政治が生える。

なぜか。

- **Compress が低い** → 話を圧縮して文書にできない → 口頭で全部話すしかない → 会議が長い
- **Archive が低い** → 記録して後から引く習慣がない → 同じ話を何度もする → 定例が増える
- **Window は中** → 口頭のやりとりは追える → 会議は成立してしまう
- **Switching は中** → 割り込みに耐えられる → 割り込みが問題視されない

そして口頭でしか情報が流通しない組織では、**会議に出た人だけが情報を持つ。** 情報の非対称は権力になる。だから政治が生じる。

## 「必然的に」という語

この Gist が優れているのは、会議と政治を **道徳の問題にしていない** ことだ。

JTC 批判は往々にして「上司が無能」「政治ばかりしている」という人格批判に落ちる。だが CCT の枠組みでは、Compress と Archive を鍛える機会がなかった人が多数派を占めている組織では、会議と政治は **物理的に必然** である。誰も悪くない。能力の分布がそうなっているだけだ。

そして、なぜ鍛える機会がないのかも自明である。**鍛えなくても出世できるから** だ。[口頭文化の勝者が制度をつくる](oral_culture_winners.md) が示すとおり、選抜は Window と Switching を測り、Compress と Archive は測らない。

## 処方は個人ではなく環境に

この診断が示す処方は、研修ではない。四つの能力のうち、後天的に外注できるのは Compress と Archive である。

- **Archive の外注** —— 検索可能な記録基盤（ただし [非同期心理的安全性](async_psychological_safety.md) がなければ誰も書かない）
- **Compress の外注** —— AI による要約（ただし [承認は注意資源である](approval_as_attention.md) が言うとおり、畳む工程を委ねると判断権も委ねることになる）

どちらも技術で埋められる。だが両方とも、埋めた瞬間に別の問題が起きる。この Wiki が繰り返し観測している「一つ解くと一つ生える」構造が、ここでも顔を出す。

## 関連する認知の軸

第 3 回走査では、類似の認知フレームが他にも複数見つかっている。

- **Memory / Attention / Sensor の三軸** —— Sensor が高く Memory が小さい人にとって、環境のコントロールは「好み」ではなく「認知アーキテクチャ上の必然」であるとされる。[ホフィス](hoffice.md) や [見通しのよい圧力](open_office_pressure.md) の議論に直結する
- **IOOO（Input/Output Orientation）** —— SOGI の構造を借りて「聞き話し優位／読み書き優位」を可視化する試み。「社会が口頭ベースで設計されている」という前提を名指すための語彙
- **選抜は言語優位、実務はビジュアル優位** —— 入口で測る能力と、中で使う能力がずれている二重バイアス

いずれも共通しているのは、**働き方の好き嫌いを、性格ではなく認知の構造として扱う** 姿勢である。性格の話にすると「慣れろ」で終わるが、構造の話にすると設計の議題になる。

## 学び

- 会議と政治は、多数派の認知 profile から **必然的に生える**。人格の問題ではない
- Compress と Archive が測られない選抜を続ける限り、その profile は再生産される
- 働き方の好みを性格の話にすると「慣れろ」で終わる。認知構造の話にすると設計の議題になる
