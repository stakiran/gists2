# 意思決定アーキテクチャとその個性

[コンセモニー](consemony.md) は「合意形成主義かつ儀式主義」という JTC の会議文化を一語で射抜いた造語だった。第 3 回走査で、その上位にあたる分類体系が見つかった。コンセモニーが病名なら、こちらは解剖図である。

## 六つのパターン

チームの意思決定を、決定権の所在で六つに分ける。

- **Solo** —— 一人が決める
- **Star** —— n 人を束ねる代表者 1 人が決める
- **Advice** —— 決める人は一人だが、助言を集める
- **Discussion** —— 議論を経て決める
- **Consent** —— 反対がなければ採用
- **Consensus** —— 全員の同意で採用

JTC が位置するのは Discussion と Consensus のあたりである。Consensus の定義がそのまま [コンセモニー](consemony.md) の前半にあたる。

> Consensus パターン：意思決定事項を常にメンバー全員に提示し、全員の同意が出た場合に限り採用する

## Consent と Consensus の距離

この分類で最も実用的なのは、**Consent** と **Consensus** が別物として置かれていることだ。

- Consensus は「全員が賛成」を要求する
- Consent は「誰も反対しない」を要求する

一見似ているが、必要な労力が桁違いである。Consensus は全員から積極的な同意を取り付けねばならない。Consent は沈黙を許容する。

JTC が遅いのは Consensus を採っているからだ。そして Consensus を採っている自覚がない。「みんなで決めましょう」という善意が、気付かないうちに全会一致要件になっている。**Consent に一段下げるだけで、会議は劇的に短くなる。** だがそれには「反対がないなら通す」という度胸が要り、その度胸は [Paper-Trail Fear](paper_trail_fear.md) が支配する組織にはない。

## アーキテクチャの個性

そして、この Gist の真の発見はここである。

> 同じアーキテクチャであっても、そのあり様は**アーキテクチャの個性**によって変わる

同じ Star パターンでも、代表者が誰か、その人がどう選ばれたか、メンバーの意欲がどうかで、まったく違う結果になる。アーキテクチャは器であり、中身は個性が決める。

> 意思決定アーキテクチャの拡張性は、個性の拡張性に左右されるのである。

**拡張性が個性に依存する。** これが JTC の硬直の正体を言い当てている。

JTC の意思決定が変わらないのは、パターンが Consensus だからではない。パターンを変えても、**個性が変わらないから** である。誰が誰に忖度するか、誰の顔を立てねばならないか、誰の一言が重いか。この個性が固定されている限り、Star に変えても Consent に変えても、同じ人が同じように決める。

これは [権威の調達](authority_procurement.md) の HiPPO 論とぴったり重なる。会議体をどう設計しても、HiPPO が固定されていれば決定者は変わらない。

## Fixed Role Paradigm

関連する観察が別の Gist にある。

> 固定的な役割スロットに人を当てるパラダイム。スロット表現力が多様性を規定し、政治を生みやすい。

役割が **スロット** として固定されているとき、組織の関心は「誰がどのスロットに入るか」に集中する。スロットの数は有限で、増えない。有限資源の配分は、必ず政治になる。

対して、役割が流動的に立ち上がっては消える設計（Fluid Role Paradigm）では、配分すべき有限資源が存在しないので、その種の政治は発生しにくい。

作者は同じ構造を、別の Gist で rigid ⇔ fluid の対比としても検討している。

> rigid <-> fluid が語呂も含めて良い対応だと思う。fluid だと臨機応変というか「必要に応じて固まることもある」ニュアンスを出せると思う。頑なに一切拘束を発生させないんじゃなくてね

「必要に応じて固まることもある」——ここに書き手の穏当さが出ている。拘束の全廃を唱えているのではない。**固まる/固まらないを選べる状態** を望んでいる。

## 学び

- Consensus（全員賛成）と Consent（反対なし）の差は、会議時間の差として現れる
- **アーキテクチャを変えても、個性が変わらなければ決定は変わらない**
- 役割がスロット化されると、有限資源の配分が発生し、必ず政治になる
