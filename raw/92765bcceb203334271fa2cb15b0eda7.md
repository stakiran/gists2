# Claude Fable 5 プロモーションアクセス整理メモ

*最終更新: 2026年7月8日*

## 結論（1行で）

**7月12日までは月額プランの週間枠（最大50%）でFable 5が使える。それ以降は使用クレジット（従量課金）でのみ利用可。**

## 経緯のタイムライン

| 日付 | 出来事 |
|---|---|
| 2026年6月9日 | Fable 5リリース（当初は6/22まで無料開放予定） |
| 6月12日 | 米政府の輸出管理指令により全世界で提供停止 |
| 6月30日 | 輸出規制解除 |
| 7月1日 | グローバルで提供再開。プロモーション開始 |
| 当初〜7月7日（PT） | プロモーション期間（当初予定） |
| **〜7月12日** | **プロモーション期間が延長**（アプリ内バナーで告知） |
| 7月13日〜 | 使用クレジット（従量課金）のみでの提供に移行 |

## プロモーションの内容

- 対象プラン: **Pro / Max / Team / Enterprise（プレミアムシート）**（Freeプランは対象外）
- 期間中、**週間利用上限の最大50%まで**Fable 5を追加料金なしで利用可能
- 対象製品: claude.ai（Web / デスクトップ / モバイル）、Claude Code、Claude Cowork
- 申請や設定は不要。モデルピッカーからFable 5を選ぶだけ

### 「最大50%」の正しい理解

- ❌ Fable 5専用のボーナス枠が別途もらえる
- ⭕ **普段の週間利用枠の中で、Fable 5に使える割合が50%までにキャップされている**（内数）

つまり:

- Fable 5を使えば、Opus / Sonnet を含めた全体の残り枠もその分減る
- 他モデルで先に枠の半分以上を消費していると、Fable 5に回せる分はその残りだけ
- Fable 5はトークン消費が他モデルより大幅に多く、**枠の減りが非常に速い**

## 7月12日以降どうなるか

1. **Fable 5はプランの週間利用枠の対象から外れる**（月額だけでは使えなくなる）
2. 継続利用するには**使用クレジット（usage credits）を有効化・購入**する
3. クレジットが有効なら、claude.ai / Claude Code / Cowork のモデルピッカーからこれまで通り選択可能
4. クレジット未設定の場合、Fable 5はモデル一覧から**選択できなくなる**
5. Opus 4.8 / Sonnet 5 など他モデルはこれまで通りサブスク枠内で利用可能

### 料金の目安（API単価ベース）

| モデル | 入力 / 100万トークン | 出力 / 100万トークン |
|---|---|---|
| **Fable 5** | **$10** | **$50** |
| Opus 4.8 | $5 | $25 |
| Sonnet 5 | $2 | $10 |

- Fable 5は現行ラインナップで最高額（Opus 4.8の2倍）
- 重いエージェント作業では短時間で数十ドル規模を消費したという実測報告もあり
- 重めのセッション1回（入力20万＋出力4万トークン想定）でFable 5は約$4、Sonnet 5なら約$0.8

## 実用的な戦略

- **期間中（〜7/12）**: Fable 5にしかできない重いタスクに集中投下
  - 大規模リファクタリング・マイグレーション
  - 複雑な長時間リサーチ
  - 自動化・ワークフロー設計の構築
- **軽い作業はSonnet / Opusへ**: 50%枠を小さな用事で浪費しない
- **13日以降**: 「仕組みはFable 5で作り、運用は軽量モデルで回す」形に落とし込む
- クレジット課金は高額になりやすいので、常用ではなく「ここぞ」の投入に限定

## 補足

- Anthropicは「**キャパシティが確保でき次第、サブスクに戻す**」方針を表明済み（時期は未定）。恒久的にクレジット専用と決まったわけではない
- Fable 5の利用には安全監視のための**30日間のデータ保持**が適用される。機密性の高い業務データを扱う場合は要確認
- 残り枠は各自の利用ダッシュボード（設定 > 使用状況）で確認可能
