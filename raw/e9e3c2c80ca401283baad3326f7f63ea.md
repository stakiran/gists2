# フルリモート企業は「出社を担う側」をどう処遇できるか — さくらインターネットの件と『Remotism』を読んで

## 背景

https://togetter.com/li/2721177 2026年7月、GMO・熊谷氏の「在宅勤務完全廃止」宣言に対し、さくらインターネット・田中社長が「フルリモートは廃止しない」と表明して支持を集めた。一方、元データセンター勤務を名乗るアカウント（@project_AKI_）が引用で反応し、次の問題を指摘した。

- データセンターは24時間365日の現地勤務で成り立っており、リモート社員の働き方は現場出社者に支えられている
- 現場勤務者は在宅勤務制度の恩恵を受けられない一方、待遇面で「現場だから報われている」とも感じられなかった（出社すると住宅補助が減る、など）
- 在宅枠は本来公平に使う想定だったが、実際は発言力の強い人が上限まで使い、残りのメンバーが出社を担っていた
- 監視・保守・障害対応などの維持業務より別の業務の方が評価されやすく、「出社組が評価されにくい業務、在宅組が評価されやすい業務」という不公平構造があった
- 現場の声が経営層に届いていないように感じた

ここから「フルリモートをベースにしつつ、出社組も適切にフォローした上手い会社の事例はあるか？」という問いを立てて調べた。

## 1. 実務事例の調査結果

「フルリモート＋現場職フォロー」を体系的にやり切って公表している決定版の事例は、公開情報の範囲ではほぼ見当たらなかった。部分的な事例は要素ごとに存在する。

### 金銭で非対称性に値付けした例

- **GMOインターネットグループ**（2020年）: 原則在宅勤務下で、やむを得ず出社せざるを得ない業務の担当者に1日5,000円の「緊急出勤手当」を支給。「リモートが標準、出社は追加負担なので追加報酬」という設計。皮肉にも今回フル出社宣言をした側の会社が、最も分かりやすい先行例になっている
- **アジャイルウェア**: 1日4時間以上の出社に1日2,000円の出社手当＋ランチ手当500円（月10日上限、賃金規定に恒久化）
- **Acompany**: 所定時間帯のオフィス作業に1日1,000円の出社手当
- 海外のDC事業者（Equinix 等）では、シフト差額手当・オンコール手当が標準的な実務

なお、さくらの「出社すると住宅補助が減る」はこの逆で、インセンティブ設計が逆立ちしている例と言える。

### 構造ごと消した例（＝解決ではなく回避）

- **GitLab / Automattic / ソニックガーデン** など全員リモート企業は、現場職ゼロなので不公平が発生しない。ただし物理インフラをクラウド事業者に外部化しているから成立する話で、DCそのものが事業のさくらには適用不可
- 見方を変えると、これら企業の快適なフルリモートは、クラウド事業者のDCで誰かが夜勤していることの上に成り立っている。元従業員の指摘と同じ構造が、業界全体のレイヤー間で起きている

### 評価制度の面

- 公開事例は乏しい。近いのは **Google SRE のトイル計測**の考え方で、「できて当たり前の維持運用業務が評価されない」問題への数少ない体系的アプローチ
- 現場職を「オフィス職の劣化版処遇」ではなく独立した報酬体系（シフト手当込み）として扱うのが実務的な落とし所

### 反面教師

- **NTTの「リモートスタンダード」**: 有名だが現場設備系は対象外で、さくらと同種の不公平感が指摘されており、成功例とは言い難い

## 2. 『Remotism』（sta 著）は何を言っているか

- 本: https://zenn.dev/sta/books/remotism-book （無料、約23万字）
- 原稿: https://github.com/stakiran/remotism

当初「理論書は処遇の議論をしていない」と誤解していたが、原稿を通読すると **Chapter「役割分担」を中心に、リモートを支える側・出社する側の位置づけがかなり主題的に扱われている**。関連する論点は以下。

### 平等指向の解体と「役割と働き方の分離」

出社派 vs リモート派という対立構図自体を「平等指向」（全員を単一のあり方に従わせる思考）の産物として壊し、必要なあり方を n 通り併存させることを説く。役割の議論に働き方（出社必須か否か）を混ぜるなとも明言。ハイブリッドワークも「どちらに寄せるかを切り替えているだけ」と批判している。

### 表明

各役割への当事者性（意思決定者／当事者／助言者／傍観者）を明示的に表明させる仕組み。表明ばかりで他の貢献がない「サボり」には理由の開示を求めて対処する。

→ さくらの件との対応: 「発言力の強い人が在宅枠を専有し、残りが出社を担う」という暗黙の力関係で決まる分担を、可視化された役割ベースの議論に引きずり出す処方箋になっている。

### 兵農分離（ワーカー・トライアングル／ミドルオフィス／連携役）

現場仕事に専念するワーカーに改善・検討・調整まで背負わせず、メタワーカー（仕事のための仕事を担う者）と、両者をつなぐ専任の連携役を置く。連携役の責務は「ワーカーの文脈を吸い上げて伝える」こと。

→ さくらの件との対応: 「現場の声が経営層まで届かない」問題への構造的な回答。声が届くかどうかを個人の発信力任せにせず、役割として実装する。

### 二層仲介

対立する立場 A と B の間に、「A寄りの仲介者」と「B寄りの仲介者」の2枚を置く。出社/リモートの文脈が明示的に例として挙げられている（完全に片方に偏った人は実は少なく、どちらかに「寄っている」だけなので、各陣営から仲介者を出しやすい）。

### バッジとトランスパレント・ガバナンス（評価）

仕事を構成する実績を「バッジ」として事前合意し、事後評価と履歴を全社に透明化することで、評価の属人性を潰す。

→ さくらの件との対応: 属人的評価の下で「評価につながりやすい業務」に人が流れ、監視・保守という不可欠だが地味な業務が報われない問題への、理論側の答えはここにある。

### 出社のご褒美化

デフォルト・リモート下では「出社は罰ゲームの様相を呈する」と認めた上で、オフィスに宿泊機能などを持たせ、出社が多い他律派へのインセンティブに転換する提案。処遇に直接触れる数少ない箇所。

## 3. 残る空白

『Remotism』は構造（役割分担・仲介）と評価（バッジ）の理論では相当踏み込んでいる一方、次は薄い。

1. **金銭的処遇の設計**: 出社手当・給与差・住宅補助の設計はほぼ扱われていない。「出社のご褒美化」も福利厚生的なインセンティブで、報酬設計ではない
2. **物理的に現地必須な職種そのもの**: 24時間365日のシフトで回るDC勤務のようなサイトバウンド職は、本書の主対象（ナレッジワーカー）の外にある

逆に実務側（GMOの緊急出勤手当など）は金銭の値付けはできているが、評価や声の吸い上げの構造までは持っていない。

## 4. 暫定的な結論

「フルリモート＋現場職フォロー」を全部揃えた公開事例は見つからなかった。組むとしたら、

- **金銭**: 出社・シフトに明示的な価格をつける（出社手当、シフト差額、住宅補助の逆転解消）— GMO・アジャイルウェア型
- **評価**: 維持運用業務を評価指標に明示的に組み込む — SREトイル計測 or Remotism のバッジ
- **分担**: 在宅枠を発言力ではなくローテーション／表明ベースで機械的に配分する — Remotism の表明
- **声**: 現場文脈を吸い上げる連携役を専任で置く — Remotism のワーカー・トライアングル

の4点セットになる。Remotism の枠組みで言えば「シフト出社という役割にバッジと連携役を明示的に割り当てる」拡張が、理論と実務の間を埋める自然な接続になりそう、というのが現時点の整理。
