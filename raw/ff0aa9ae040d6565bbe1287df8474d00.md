# q: この人が稼げそうな売り物って何？ https://gist.github.com/stakiran/6ba08b5ed799c13de085a5369b7d7199

# ans

ログから読める「能力があって、かつ再現性がある」ものに絞ると、売れそうなのは大きく3つです。

**1. AI×執筆パイプライン（最も換金しやすい）**
誤字脱字検出スキルで10万字原稿を1周1時間未満・3周回す、という実績は、それ自体が商品になります。売り方は複数あって、①スキル/ツールとして配布（Claude Code skill やCLIとして有料 or 投げ銭）、②「AIエージェントで校正・推敲を回す」技術同人誌・Zenn本、③小説家・ライター・編集者向けの導入支援。書き手はAIを使いたいが仕組み化できていない層が厚く、しかも「自分の原稿で実戦済み」という説得力が他と違います。仕事の内容と重なる領域なので、副業規定だけ確認が必要。

**2. 「データで自分を検証する」セルフマネジメント論**
朝サーフィン問題のように、自分のif-thenをタイムスタンプで棄却する話は、巷の習慣術と明確に差別化できます。dr→wr→mrの三層レビュー、Tritask運用、損切り基準（「悩むなら仕事の延長」）をまとめた書籍・note連載・テンプレート販売。ただし自己啓発市場はレッドオーシャンなので、ネタ単体より「AIエージェントに週次レビューを手伝わせる」という1との掛け算で出すほうが埋もれにくい。

**3. AIキャッチアップの自動化そのもの**
GitHub Actionsで定期実行しているキャッチアップは、そのまま有料ニュースレターや「自分専用AI情報収集を構築する」講座の素材になります。労力ゼロで出せる点が強い。

逆に、kizamu（自作VCS）や創作本体は「売り物」というより信用の担保で、直接の収益は期待薄です。

一つ付け加えると、この人の弱点は社会関係資本なので、営業・紹介・コミュニティ運営が前提の商売（コンサル本業化、講師業）は向きません。**書けば勝手に売れる形（本・ツール・自動配信）に寄せる**のが、能力の凸凹に合った設計だと思います。1の技術書を1冊出して反応を見るのが、最も低コストな最初の一手でしょう。
