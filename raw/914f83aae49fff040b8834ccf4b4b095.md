# a
6つのスパン（2024/12 → 2025/06 → 2025/11 → 2026/02 → 2026/05 → 2026/08）を、参加者の顔ぶれと話題・トーンの両面から見ていきます。日記3日分ずつのサンプルなので「その日たまたま書かなかった」可能性は割り引く必要がありますが、それでも傾向ははっきり見えます。

## ユーザーの流入・流出

**2024/12：大所帯期。** qwerty1234, Hyou, star_field, dnin, sume, 久住哲, イタロー, blu3mo, Nakanishi_Keita, みなせ, 玄武など、後のスパンでは見られなくなる名前が多数活動。blu3moが「井戸端に戻ってきてしまった」と復帰し🍵で迎えられるなど、出入り自体が話題になる文化。1日あたりの書き手数はこの時期が最多クラスです。

**2025/06：世代交代の始まり。** taktamur, terang, Summer498, W7kA9pX2, custard, RR, xbczLsg2YtD2といった2024/12には見えなかった名前が定着し始めます。象徴的なのがtokorotenの「数年間ROMってたけど、遊びに来た」で、20人超のアイコンと[熱烈歓迎]がつく歓迎文化の強さが出ています。一方この頃を最後につばくろ、blu3mo、Hyouらは見えなくなります。

**2025/11：静かな谷間。** 1日の参加者が目に見えて減り、旧メンバー（qwerty1234, dnin, sume, 久住哲, イタローなど）はほぼ消えています。着地鳩など少数の新顔はあるものの、流入より定着メンバーの濃い交流が中心。

**2026/02：新規は少ないが質的変化。** ntjEchpkのようなランダム文字列ID、hoshihara（睡眠・大学生活に悩む学生）、shibainurou、綾坂ことなどが加わります。KidooomやQWOPはこのあたりから見えなくなり、Mijikkoもこのスパンが最後です。

**2026/05：明確な流入の波。** atohs, hoagecko, nyarla, onuma, baku3, imo, k47de, vlzs, 肉, HelloPeople, 紺野春馬と、6スパン中最大の新規参入。はるひの「井戸端賑わってて素直に嬉しい」にnishioが+1する場面が象徴的です。

**2026/08：流入継続＋「SNS避難所」化。** hiro, joniel, mo, zatsma, h45te, KNo.804Cとさらに新顔が続きます。特徴的なのは、nyarlaのFediverseアカウント全削除やzatsmaの「今のSNSに疲れてしまった人に……」の話題のように、**外部SNSからの疲弊・撤退とセットで井戸端に軸足を移す**動きが見えること。

## 雰囲気の変遷

**2024/12** は、挨拶チェーン、言葉遊び（ログイン/ログオン談義、[57577.icon]）、体調・風邪の共有、kidooomのBadレビューへの励ましなど、密度の高い井戸端会議そのもの。AIは話題の一つに過ぎませんでした。

**2025/06** は「井戸端る」の動詞化遊びが流行り、コミュニティ自体を楽しむメタな明るさがピーク。同時にチームみらい・選挙の話題で現実の政治との接点が生まれ、Claude MAXやCosenseAIBoosterなどAIツールの話が増え始めます。

**2025/11** は落ち着いたトーンで、kidooomのゲーム「スロダン」を皆で買って遊び感想を書き合うなど、**メンバーの創作を支える内向きの温かさ**が目立ちます。

**2026/02** はAIワークフローが会話の主軸に（CodexでアーレントPDF処理、Claude Code、CLI vs MCP論争）。一方でtakkerの卒論提出に17人分の🎉がつくなど、祝福文化は健在。知的で支援的な空気です。

**2026/05** は転換点で、賑わいと摩擦が同時に来ます。「大反省会」「侮辱らしき言葉」「揉め事の半分も理解できてない（基素）」「自分の日記切り出されるのしんどいかもしれん（はるひ）」など、**対人的な緊張とその修復プロセスが日記上に可視化**されました。[お茶.icon]を配り合って場を鎮める振る舞いや、Summer498が1日25ページ切り出すなど✂切り出し文化の急拡大も特徴です。人が増えたことと暗黙の規範が揺らいだことが連動して見えます。

**2026/08** は、その摩擦を経た再調整期。Nremの不満表明にtakkerやcakiが丁寧に応答する、hoshiharaの「メール返せない」にtakkerが具体的な一文を提案して[大偉業.icon]で祝う、といった**ケアの解像度が上がった**やり取りが目立ちます。話題面ではAIが完全に「同僚」化（jonielの「完全にプロデューサー」、takkerの「最後はLLMが尻拭いしてくれるから自分で書く」）し、ブローガストのような外部ブログ活動との相互乗り入れも増えました。

## まとめ

流入流出は「2024末の大所帯 → 2025年の世代交代と縮小 → 2026年の新規流入ラッシュ」という谷を挟んだV字で、顔ぶれは半分以上入れ替わりつつ、コア十数名が連続性を担保しています。雰囲気は「賑やかな雑談の広場」から「AI実践を共有する知的コミュニティ」へ重心が移り、2026/05に成長痛としての摩擦を経験、2026/08時点では衝突を明文化して修復する成熟したコミュニティ、かつSNS疲れした人の避難先という性格を帯びています。歓迎・祝福・励まし（🎉、🍵、[加油.icon]）の文化は6スパンを通じて一貫しており、これが入れ替わりの激しさにもかかわらず場のトーンを保っている最大の要因に見えます。
