失礼しました。日本語にしても直らないなら、その三択はリモート接続には効かない設定だと思われます。

その三択はおそらく接続先Windowsの「ハードウェア キーボード レイアウト」の設定です。これは本来、そのPCに直接つないだキーボード用の設定です。Windows App 経由のリモート接続では、先ほど説明したとおり「接続時に接続元から送られる情報」で配列が決まるので、この設定が無視されてしまうことがよくあります。日本語を選んでも直らないのはそのためです。

この「接続時の判定」を確実に日本語にするには、前にお伝えしたレジストリ変更(`Layout File` を `KBD106.DLL` にする)がいちばん効きます。接続元から何が送られてきても、日本語の配列表を使うように固定できるからです。

手順をもう一度まとめます。接続先で管理者としてコマンドプロンプトを開き、バックアップ、変更の順に実行して、接続先を**再起動**します。

```
reg export "HKLM\SYSTEM\CurrentControlSet\Control\Keyboard Layouts\00000411" "%USERPROFILE%\Desktop\kbd_backup.reg"
```
```
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Keyboard Layouts\00000411" /v "Layout File" /t REG_SZ /d "KBD106.DLL" /f
```

三択の設定を変えた後、サインアウトや再起動をせずに再接続しただけだったなら、念のため一度接続先を再起動してから試す価値はあります。それでも駄目なら、レジストリに進んでください。管理者権限がなくコマンドが拒否される場合は、IT担当に「Windows App で接続すると日本語キーボードがUS配列になる。ハードウェアキーボードレイアウトを日本語にしても直らない」と伝えれば、この対処にたどり着くはずです。
