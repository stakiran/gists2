# q マネージャーの類型を知りたい。俺が知ってるのは中間管理職的なビジネス寄りのマネージャーと、エンタメ業界でタレントにつく世話係的なマネージャー。他は？

# a
いろいろあるよ。ざっくり分けるとこんな感じ。

**「物事」を管理するマネージャー(人の上司ではない)**
- プロダクトマネージャー(PM):製品の企画・方向性に責任を持つ。部下がいないことも多く、「権限なきリーダーシップ」と言われがち。
- プロジェクトマネージャー:期限・予算・進行の管理。プロダクトマネージャーとは別物。
- ファンドマネージャー:投資家から預かった資産の運用を指揮する人。

**「場所・施設」を仕切るマネージャー**
- 店長・支配人系:ストアマネージャー、ホテルの支配人(ゼネラルマネージャー)、レストランのフロアマネージャーなど。英語圏で日常的に "manager" と言うとまずこれ。クレームで「マネージャー呼んで!」のやつ。
- プロパティマネージャー:賃貸物件の管理・入居者対応をする不動産管理者。

**スポーツ系**
- 監督としてのマネージャー:野球の監督は英語で manager、サッカーもイングランドでは監督を manager と呼ぶ(戦術だけでなく補強まで仕切る)。
- GM(ゼネラルマネージャー):プロ球団でトレードや契約などチーム編成を担う役職。現場の監督とは別。
- ボクシングのマネージャー:選手の契約交渉や興行のマッチメイクを担当。エンタメ系マネージャーに近い。
- 部活のマネージャー:日本独特の用法で、雑務・記録・サポート係。海外の感覚とはかなりズレる。

**その他の専門職**
- ケアマネージャー(介護支援専門員):日本の介護保険制度上の資格職で、ケアプランを作る人。
- アカウントマネージャー:営業職で、特定顧客との関係を維持・拡大する担当者。
- コミュニティマネージャー:オンラインコミュニティやファンコミュニティの運営役。
- ツアーマネージャー/ロードマネージャー:音楽業界でツアーの移動・宿泊・機材などを回す人。タレントマネージャーの現場特化版。

**おまけ:人間ですらないマネージャー**
パスワードマネージャー、ウィンドウマネージャー、タスクマネージャーなど、ソフトウェアにも大量にいる。

共通するのは「何かに責任を持って回す役」ってことだけで、対象が人か、物事か、場所か、金か、で全然別の職業になるのが面白いところ。

# q
タレントのマネージャーはどこ？日本固有？

# a
タレントマネージャー自体は世界中にいるよ。ただ、日本型の「世話係」的な形はかなり独特で、同じ「タレントのマネージャー」でも中身が国によって全然違う。

**アメリカ型:独立した戦略参謀**
ハリウッドや米音楽業界では役割が分業されてる。

- エージェント:仕事(出演・出版契約など)を取ってくる係。免許制で、報酬は原則ギャラの10%上限など規制がある。
- タレントマネージャー(パーソナルマネージャー):キャリア戦略の相談役。どの仕事を受けるか、どうブランドを作るか。報酬は歩合(15〜20%程度)で、タレントが「雇う」側。
- さらに弁護士、パブリシスト(広報)なども別々に契約する。

つまり米国のマネージャーは、タレント本人がクライアントで、マネージャーは個人事業主か独立会社。車の運転や現場の付き添いはやらない(それはアシスタントの仕事)。

**日本型:事務所の社員**
日本ではタレントが芸能事務所に所属し、マネージャーは事務所の従業員。スケジュール管理、送迎、現場対応、営業まで一人で幅広くやる。タレントとマネージャーの間に直接の契約関係はなくて、力関係も「事務所>タレント」になりやすい。新人マネージャーが運転手兼付き人から始まる、みたいなキャリアパスも日本的。

**韓国型:日本に近い**
K-POP事務所のマネージャーも事務所所属の社員で、送迎や現場帯同をやる世話係スタイル。日本型に近い。

なので整理すると、「タレントに専属でつく職業」は世界共通だけど、あなたが挙げた「世話係的マネージャー」という形は日本(と韓国など東アジアの事務所システム)に特徴的で、欧米だと同じ肩書きの人はもっと経営コンサル寄り、世話係部分はアシスタントや付き人に分離されてる、という感じ。
