# AviUtlで書き出した動画の手ブレをffmpegで補正する

AviUtlには手ブレ補正機能がないため、AviUtlで書き出したAVIをffmpegの「vidstab」で補正し、mp4にします。解析→補正の2回実行するだけです。

## 準備

- vidstab入りのffmpegを用意（Windowsなら gyan.dev 配布の essentials / full 版に含まれる）
- 確認：`ffmpeg -filters | findstr vidstab` で `vidstabdetect` と `vidstabtransform` が出ればOK
- コマンドは動画と同じフォルダで実行（パスが通っていなければ ffmpeg.exe をフルパスで指定）

以下、入力を `input.avi`、出力を `output.mp4` とします。

## 手順

### 1. 揺れを解析する

```
ffmpeg -i input.avi -vf format=yuv420p,vidstabdetect=shakiness=5:accuracy=15:result=transforms.trf -f null -
```

同じフォルダに `transforms.trf` ができます。

### 2. 補正して書き出す

```
ffmpeg -i input.avi -vf format=yuv420p,vidstabtransform=input=transforms.trf:smoothing=30:optzoom=1,unsharp=5:5:0.8:3:3:0.4 -c:v libx264 -crf 18 -preset slow -c:a aac -b:a 192k output.mp4
```

最後に `video:...kB audio:...kB` の行が出てプロンプトに戻れば完了です。

## 調整

| パラメータ | 内容 |
| --- | --- |
| `shakiness` (1〜10) | 揺れが激しいほど大きく |
| `smoothing` | 大きいほど滑らか。意図したパンまで消えるなら小さく |
| `optzoom=1` | 補正でできる黒い余白を自動拡大で隠す（0で無効） |
| `unsharp=...` | 補正によるボケを軽くシャープに。不要なら削除 |

## つまずきポイント

- **`format=yuv420p` を必ず入れる**：AviUtlのAVIはRGB（bgr24）などで出力されることがあり、そのままだと2パス目がエラーも出さずに止まったり、4:4:4形式のmp4になって一般的なプレーヤーでブロック状に崩れたりします。
- **音声はAACに変換**：AVIの音声は無圧縮（PCM）なので、mp4では `-c:a aac` を指定。
- **mp4は書き出し完了まで再生できない**：変換中に開くと「壊れている」ように見えます。
- **`transforms.trf` はファイル名だけで指定**：`D:\...` のようにドライブ名を含めると `:` の解釈でエラーになりやすいです。
