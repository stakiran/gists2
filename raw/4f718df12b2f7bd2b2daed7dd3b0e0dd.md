# 大手個人VTuberと企業の関わり方 — 商標・登記から見る4つの型

有名個人勢VTuber4名（結城さくな・しぐれうい・周防パトラ・名取さな）について、「個人勢の裏には企業がいるのか？」という問いを、商標出願・法人登記などの公開情報から整理したメモ。

**結論を先に言うと**：4人とも何らかの形で法人・企業が絡んでいるが、その関わり方は全員バラバラであり、ホロライブ等の「運営企業に所属している」状態とはいずれも異なる。「個人勢＝完全に一人」でも「実は企業に運営されている」でもなく、**活動規模に応じて法人という器をどう使うかの選択がそれぞれ違う**、というのが実態に近い。

*最終更新：2026年8月14日。情報は執筆時点の公開情報に基づく。*

## 各論

### 1. 結城さくな — 専用法人「株式会社なめらかプリン」型

- 商標「結城さくな」（商願2024-136169）は**株式会社なめらかプリン**（東京都）名義で2024年12月18日に出願。第3類（せっけん類）・9類・14類・16類・18類・21類・24類など**12区分・256の商品役務**に及ぶ。個人の防衛的出願ではなく、化粧品からグッズまで本格的な商品展開を前提としたIP管理。
- 法人登記を調べたネット記事によれば、同社の設立は2024年11月20日（初配信2024年10月27日の直後）、所在地は渋谷のレンタルオフィス、代表取締役は本人とは別人物とされる。※まとめブログ由来の情報のため精度には留保。
- **読み方**：設立時期と事業内容から、「裏にいた既存企業」ではなく**活動開始に合わせて作られた資産管理・マネジメント法人**と見るのが自然。ただし法人の実質的支配者（株主）は登記簿に載らないため、本人の個人事務所なのか第三者が関与するのかは公開情報では確定できない。既存大手VTuber事務所の名義は商標にも登記にも登場しない。なお旧名義と噂される「xxx」の商標は依然xxxx株式会社が保有しており、資本的に切れていることの傍証になっている。

### 2. しぐれうい — 専属エージェンシー「アンコロール株式会社」共同型

- 「しぐれうい」ロゴ（商願2024-110160）やプロデュースキャラクター「雨衣」のロゴ（商願2024-102237）は**アンコロール株式会社**名義で出願。公式ガイドラインにも「アンコロール株式会社としぐれういが権利を有する」と**法人と個人の共同権利**であることが明記されている。
- アンコロールは東京都渋谷区所在、資本金250万円・従業員10人以下の小規模企業で、2024年にクリエイター特化型エージェンシー「INCOLORE」を設立。しぐれういのライブ・個展・VoiSona「雨衣」販売を共同で手掛ける。会社ロゴの原案・監修をしぐれうい本人が担当している点からも、本人と一体的に作られた会社である可能性が高い。
- 「しぐれうい」名義の商標は活動範囲の広さを理由に一度拒絶通知を受けたのち、活動開始から6年以上経ってようやく登録に至ったとされる（SNS上の観測情報）。
- **読み方**：「裏で操る大企業」ではなく、**しぐれうい事業を回すために組成された専属エージェンシー**。個人勢だが、契約・イベント・権利管理の窓口は企業が担う体制。

### 3. 周防パトラ — 事務所からのIP買い戻し型（逆方向）

- 4人の中で唯一の元・企業所属。2018年に774inc.（後のななしいんく）傘下ハニーストラップでデビューし、**2023年5月9日に事務所保有の権利を自ら買い取って独立**。チャンネル・アーカイブ・見た目・衣装をそのまま引き継いだ。本人いわく「ローンが32年から35年に伸びた」ため、法人買収ではなく個人資金での買い取りとみられる。
- J-PlatPat簡易検索で商標「周防パトラ」は**0件**。これは（a）事務所時代からそもそも商標出願されていなかった、（b）独立時の「IP買い取り」の実体は著作権譲渡＋チャンネル譲渡であり商標権移転を伴わなかった、と考えると整合的。カバーやANYCOLORのようにタレント名を網羅的に商標登録する大手と異なり、中堅事務所はコスト面から個別タレント名まで登録しないことが多い。
- 独立から3年経っても本人側の出願が確認できないのは、円満独立で係争リスクがなく、著名な芸名は商標法4条1項8号（他人の著名な芸名と同一・類似の商標は本人の承諾なく登録できない）により無登録でも一定の防御が効くため、費用をかける動機が薄いからと推測できる。
- **読み方**：他の3人とは逆方向で、**企業名義だった権利が個人側に移転した事例**。「裏に企業」がいたのは過去の話で、現在は最も純粋な意味での個人保有。

### 4. 名取さな — 外部制作会社「株式会社TRIBALCON.」連名型

- 本人はXプロフィールで「個人でやってます」と明言。一方、誕生日イベント「さなのばくたん。」は初回（2020年）から**主催：名取さな / 株式会社TRIBALCON.** の連名で、イベント公式アカウントの運営者表記も同じ連名。少なくとも6年以上続く長期パートナーシップ。
- TRIBALCON.は2015年設立・渋谷区所在（法人番号3011001108729）の、エンタメ系デザインチームBALCOLONY.のグループ会社。3DCG・モーションキャプチャ・ライブ演出を手掛ける技術会社で、しぐれういの3Dお披露目配信も担当するなど**名取さな以外の案件も普通に受けている独立系企業**。
- 「名取さな」名義の商標は、出願人を特定できる公開情報が見つからなかった（J-PlatPatで称呼「ナトリサナ」の確認を推奨）。グッズはグッドスマイルカンパニーのフィギュアやSEGA音ゲーコラボなど大手経由で多数展開されており、仮に商標未登録なら著作権ベースのライセンス契約だけで回していることになる。
- **読み方**：しぐれうい型と似て非なる型。アンコロールが「本人のために作られた会社」なのに対し、TRIBALCON.は**本人のデビュー前から存在する外注先・共同主催者**であり、専属の裏方組織ではない。権利や名義の主体は一貫して個人側にあるように見え、4人の中で「裏に企業がいる」度合いは最も薄い。法人化せずに映画館イベント・TV出演・大手グッズ展開の規模を8年維持している珍しいモデル。

## まとめ：4つの型と、そこから言えること

企業との関わり方をスペクトラムとして並べると次のようになる。

```
企業の関与が濃い ◀──────────────────────────▶ 薄い

［事務所所属］   結城さくな型      しぐれうい型       名取さな型      周防パトラ型
 ホロライブ等    専用法人が権利を   エージェンシーと    制作会社と       権利を個人が
 （比較対象）    一元管理          権利を共同保有      連名で協業        完全保有
```

1. **「個人勢」とは「タレント事務所に所属していない」という意味であって、「企業と無関係」という意味ではない。** 4人とも法人・企業と何らかの形で関わっている。
2. ただしその法人は、いずれも**税務・契約・知財管理・興行実務のための器**であり、既存の大手VTuber運営企業が出願人・権利者として登場する形跡はない。「実は大手に運営されている」ことを示す公開情報は4人の誰についても見当たらない。
3. 商標の打ち方に体制の「重さ」がそのまま表れる。初配信2か月以内に12区分を固めた結城さくな、6年かけて登録したしぐれうい、3年経っても出願ゼロとみられる周防パトラ、確認できない名取さな——**商標戦略の差は、背後の資本・体制の差の代理指標**として読める。
4. 限界として、法人の実質的支配者（誰が株を持っているか）は商業登記簿には記載されないため、「代表者と本人の関係」という最後の一歩は公開情報では確定できない。本メモの「〜とみられる」はすべてこの留保付き。
