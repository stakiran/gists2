# Mac mini まとめ

> 2026年10月時点の情報。価格は Apple 公式の税込価格。

## Mac mini とは

Apple が販売する小型のデスクトップパソコン。手のひらに乗るほどの箱型の本体（約13cm四方・1kg未満）だけが売られており、モニター・キーボード・マウスは自分で用意して接続する。

## MacBook との違い

| | Mac mini | MacBook（Neo / Air / Pro） |
|---|---|---|
| 形 | デスクトップ（本体のみ） | ノートパソコン（一体型） |
| 持ち運び | 基本は据え置き | どこでも使える |
| 必要なもの | モニター・キーボード・マウスを別途用意 | 買ってすぐ使える |
| バッテリー | なし（要コンセント） | あり |
| 端子の数 | 比較的多い | 少なめ |

同世代なら中身のチップ（Apple Silicon）の性能は近い。「同じ頭脳をノート型で使うか、箱型で使うか」の違いと考えるとわかりやすい。

## 誕生の経緯

- **2005年1月**、Macworld Expo でスティーブ・ジョブズが発表。初代は PowerPC G4 搭載、米国価格 **499ドル**。
- 当時は iPod が大ヒットしており、iPod を使う **Windows ユーザーを Mac に呼び込む** のが狙い。
- コンセプトは **BYODKM**（Bring Your Own Display, Keyboard, Mouse）。手持ちの周辺機器を流用してもらうことで本体価格を下げた。
- その後 Intel チップ、2020年からは Apple 独自の M シリーズへ移行。現在は小型・高性能を活かし、作業機やサーバー用途でも人気。

## Windows ユーザーでも使える？

使える。もともと乗り換え組を想定した製品。

**そのまま使えるもの**
- Windows 用のキーボード・マウス・モニター
- Chrome、Microsoft Office、Zoom、LINE、Spotify など主要アプリ
- USB メモリや外付けストレージ

**戸惑いやすい点**
- ショートカットは Ctrl ではなく主に **⌘ Command**（コピーは ⌘+C）
- エクスプローラー → **Finder**、タスクバー → **Dock**、閉じるボタンは左上
- Windows 専用ソフトはそのままでは動かない
- PC ゲームは Windows より対応タイトルが少ない

### JIS 配列キーボード

- 問題なく使える。初回接続時の「キーボード設定アシスタント」で **JIS** を選べば記号も刻印どおりに入力できる（後からシステム設定でも変更可）。
- Windows キー → ⌘ Command、Alt → ⌥ Option として動作。
- 「半角/全角」「無変換」「変換」キーは Windows と同じように動かないことがある。対策：
  - `Control + Space` などで入力切り替え
  - 無料アプリ **Karabiner-Elements** で「無変換→英数」「変換→かな」に割り当て
- Apple 純正 JIS 配列 Magic Keyboard なら設定不要（「英数」「かな」キー付き）。

### 1920×1080（フルHD）ディスプレイ

- HDMI でつなぐだけで使える。
- ただし macOS は高解像度（Retina）前提で、低解像度向けの文字くっきり処理をしないため、**Windows より文字が少しぼやけて見える** ことがある。
  - 21〜24インチ：普段使いなら気にならない人も多い
  - 27インチ：粗さが目立ちやすい
- 新しく買うなら **27インチ 4K** がおすすめ。

## 持ち運びはできる？

本体は小さく軽いので物理的には簡単。ただし **バッテリーなし・周辺機器が必要** なので、カフェなどでサッと使う用途には不向き。

向いている使い方：
- 自宅と職場の両方にモニター等があり、本体だけ持ち運ぶ
- 出張先のホテルのテレビに HDMI 接続
- モバイルモニターと組み合わせる

外で使う機会が多いなら MacBook のほうが快適。

## 似たような小型デスクトップ

- **Windows ミニPC**：Intel NUC（2023年から ASUS が事業継承）、Minisforum、Beelink、GMKtec など
- **Mac Studio**：Mac mini の兄貴分にあたるプロ向け高性能機
- **Raspberry Pi**：名刺サイズの基板コンピュータ。電子工作・学習・自宅サーバー向け。キーボード一体型の Raspberry Pi 500 も
- **Mini-ITX 自作PC**：小型ケースに高性能パーツを詰め込む自作の世界
- **歴史的名機**：Power Mac G4 Cube（2000年、MoMA 収蔵）、NeXTcube
