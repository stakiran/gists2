# 「資生堂ショック」から考える、資生堂の戦略と美容部員の未来

2026年8月時点の公開情報をもとに、資生堂の働き方改革・経営不振・再建戦略について議論した内容の整理。

---

## 1. 資生堂ショックとは（時系列）

| 時期 | 出来事 |
|---|---|
| 1991年 | 法定より早く短時間勤務制度を導入。「女性に優しい会社」の代表格に |
| 2007年 | 美容部員（BC）にも時短制度の利用を推奨 → 利用者が急増 |
| 2007〜2014年 | 時短者が平日早番に集中。繁忙帯（夜・土日）を子育て中でない社員や経験の浅い派遣社員がカバーする運用に。販売機会の損失・現場の不公平感が蓄積 |
| 2014年4月 | 育児中の時短社員にも遅番・土日勤務を求める方針に転換。個別聞き取り＋ベビーシッター代補助などの環境整備とセット |
| 2015年 | 日経新聞・AERA・NHK「おはよう日本」が報道。「資生堂ショック」という言葉が拡散。「時短勤務者に冷たい」との批判と「保護から戦力化へ」との評価に分かれる |

**要点**：一見「女性に厳しくなった」話に見えるが、実態は「時短者の増加で崩れた現場の公平性の是正」＋「時短者にもキャリア形成機会を与える戦力化」の二本立て。

## 2. その後の展開

- **2015〜2016年**：正社員BCの新規採用を11年ぶりに再開、契約社員約2,000人の正社員化を推進。「厳しくする」と「待遇を上げる」をセットで実施
- **2017年〜**：女性リーダー育成塾などで登用が本格化
- **成果**：女性管理職比率は国内41.1%・グローバル59.5%（2025年1月時点、日本平均は約13%）。なでしこ銘柄5年連続選定、「女性が活躍する会社BEST100」総合1位常連
- **2024〜2025年**：一転して経営難。美容部員約7,000人の売り場別担当制（百貨店/ドラッグストア等）を撤廃し兼務化。BCは資生堂ショック当時の約1万人から3割減

## 3. 経営難の原因 —— 業界のせいか、資生堂のせいか

**結論：両方だが、資生堂固有の判断ミスの比重が大きい。**

業界共通の逆風：
- 中国の景気後退と現地メーカーの台頭
- トラベルリテール（免税）の減退、インバウンド回復の遅れ

しかし花王は化粧品事業を黒字転換（営業利益104億円）、コーセーも純利益2倍と、同じ環境で競合は回復。資生堂固有の要因：

1. **中国・免税への過度な依存**：成長シナリオを中国一本足に賭けた
2. **「選択と集中」の裏目**：2021年にTSUBAKI・専科等の中低価格帯を売却しプレミアム偏重に。高価格帯は需要の母数が小さく景況に脆い。国内市場の顧客を競合に奪われたとの批判も
3. **M&Aの失敗**：2019年買収の米Drunk Elephantで減損468億円 → 2025年12月期に過去最大の最終赤字520億円
4. **経営体制**：中国事業への過度な傾注を招いた戦略立案体制への批判

## 4. 2014年の働き方改革は「ヘタクソ」だったか

議論の中で検討した代替案と、その評価：

### 案A：昇進を望まない人向けのトラックを作り、一律負荷をやめる
- 正論だが問題の核心とズレ。核心は昇進ではなく**シフトの穴埋め**。誰かの「定時で帰る自由」は別の誰かの「定時で帰れない義務」と表裏一体で、改革前は後者を子育て中でない社員が負っていた
- なお実際の運用は完全一律ではなく、個別聞き取り＋シッター代補助つき

### 案B：繁忙帯（夜・土日）の報酬を大幅に増やす（補償賃金格差）
- 経済学的には王道。ただし
  - 夜働けない理由の多くは物理制約（保育インフラ）でカネでは解けない
  - 必要なプレミアムが高額になり人件費を圧迫
  - 時短者が繁忙帯経験を積まないマミートラックを制度として固定化し、「戦力化」の目的と逆行
- **結論：対立案ではなく併用すべき補完策。「公平分担＋個別調整」を基本に、割増で「押し付けられ感」を「選んで得してる感」に変えるのが最適だった**

### 案C：繁忙帯の接客をアルバイト・非正規に任せる
- **既に試されて失敗した側の選択肢**。2007〜2014年の運用がまさにこれで、販売機会損失と戦力不足を招き改革の引き金になった
- プレステージ接客は技能集約的（肌診断・タッチアップ・指名客との長期関係）。離職率の高い非正規に研修投資は回収できない
- セルフ販売のドラッグストアや中価格帯なら有効だが、それを突き詰めると美容部員という職種自体が不要になる方向に進む

### 総括
2014年の改革は「下手」というより、繁忙帯が固定された接客業で公平性を保つには筋の良い代替案が乏しかった。真に批判されるべきは (1) 2007〜2014年の7年間の放置、(2) 割増手当という価格メカニズムの活用不足。

## 5. 現在の資生堂の戦略

**明確に高技能・プレミアム路線。薄利多売には戻れない（戻る足場を売却済み）。**

- **商品**：プレミアムスキンビューティー事業の拡大。ブランド価値向上に3年間で1000億円超の追加投資
- **人材**：高技能者を減らして薄く広く効かせる。縦割り撤廃による兼務化、BCのSNS発信（パーソナルビューティーパートナー＝PBP）による1対多への接客拡張
- **構造改革**：「ミライシフトNIPPON 2025」で2年間250億円のコスト削減＋約1,500人の早期退職。米国でも人員削減・オフィス縮小
- **効果**：2026年上期は売上6.2%増・営業利益約2.3倍・最終利益約3.1倍。コスト削減効果160億円、米州黒字転換。ただし実質売上は横ばい圏で「売る力」の回復はこれから
- **2030中期経営戦略**（2025年11月発表）：2026年にコア営業利益率7%達成 → 2030年に10%以上。年平均売上成長率+2〜5%。ROIC 10%以上を規律に。控えめな成長目標＋資本規律重視で、高値掴み買収への反省が制度化された

## 6. 売上を伸ばすには —— 議論した打ち手

### 前提：本当の強みは「高級」ではない
高級市場にはロレアル・エスティローダー・LVMHがひしめき「高い」こと自体に差別性はない。本物の強みは：
1. **皮膚科学の研究開発力**（150年の蓄積、細胞老化研究など）
2. **「日本発」ブランド資産**（アネッサはアジアUVケア首位）
3. **接客・カウンセリングの人的資本**

### タッチポイント問題
「店舗しかやってない」は誤解（EC化率33%、Beauty Key・バーチャルメイク・ライブコマース等を展開）だが、**「重心が一世代前」は正しい**：
- デジタル施策が「店頭のネット移植」発想で、TikTok等の「発見される場所」に弱い
- プレミアム戦略とバズ販促の構造的な相性の悪さ
- 顧客層の高齢化との自己強化ループ

### 検討した新規案①：パーソナル化粧マネジメント
各人に最適な化粧の「塩梅」を継続追求するサービス。アプリと対人の二本立て。

- 部品（肌パシャ、オンラインカウンセリング、PBP）は既に存在。欠けているのは**継続性＝「かかりつけ医」化**で、そこは本当に空席
- アプリ単体：継続率の壁。対人単体：スケールの壁（BC 7,000人×数百人が上限）
- **最適解は階層構造**：アプリで日常記録、四半期に一度の対人面談（ウェアラブル＋定期健診モデル）。資生堂の文脈では対人を課金の柱、アプリを無料入口に
- 最大の障害：BCの評価制度（今日の売上で測る仕組み）の作り直しが必要

### 検討した新規案②：BC 7,000人のタレントプール化＋店舗の高齢顧客特化
- **パーソナル案より分が良い**。限界費用が軽く、最大の弱点（若年層との接点）に直接効く。既にPBPのSNS発信として小規模に実証済み
- 「プロ資格を持つ顔の見える社員」は、案件まみれの素人インフルエンサーと企業広告の間の第三のポジションを取れる
- 4つの罠：
  1. **べき乗則**：跳ねるのは数十人。全員義務化は資生堂ショックの過ちの再演。選抜・育成方式が必須
  2. **スターの流出**：有名になったBCは独立が合理的。収益シェアやアンバサダー契約など「社員」を超えた報酬設計が必要。逆手に取れば「スターへの登竜門」という採用ブランドになる（吉本興業モデル）
  3. **統制と魅力のトレードオフ**：薬機法・ブランドガイドラインと「本音っぽさ」の両立
  4. **換金導線**：再生数→購買の接続（担当ECページ・社内アフィリエイト的仕組み）
- 高級ブランドとの緊張：クレ・ド・ポーの神秘性と親近感発信は同居困難。ブランド別トーン設計まで含めて完成形

## 7. 結論

出てきた代替案（報酬、非正規化、EC、パーソナル化、インフルエンサー化）は、実は業界が過去15年で検討・実行してきた選択肢とほぼ一致する。**この問題の解空間は狭い**。

そして全ての案が最後に突き当たる壁は同じ：**「美容部員という職能をどう定義し、評価し、報いるか」**。商品戦略やチャネル戦略に見える問題が、掘ると必ず人事制度に着地する。

資生堂ショックが10年語り継がれる本当の理由はここにある。あれは働き方改革の一事例ではなく、「人が資産の会社は、人の制度を変えないと戦略を変えられない」という普遍的な話である。

方向性自体は収束している——高級×サイエンス路線の維持、店頭の選択と集中、SNSと人による発見接点、職能の多様化に合わせた評価・報酬の分解。問題は方向ではなく速度と徹底度。2〜3年後の答え合わせが楽しみな局面だ。
