# Dia ブラウザ メモ（2026-09-02 時点）

Windows ベータの waitlist が回ってきたので触ってみた。第一印象は「サイドバーに AI チャットが付いた Chromium」で、目新しさは薄い。調べた範囲でその印象がどこまで妥当かを整理する。

## 基本情報

- 開発元: The Browser Company（Arc の開発元）。2025年10月に Atlassian が 6.1 億ドルで買収し、現在は Atlassian 子会社
- Chromium ベース。Arc の後継として 2024年12月に発表、2025年6月に Mac 向けベータ、2025年10月に招待制を撤廃
- Arc はメンテナンスモードに入り、開発リソースは Dia に集中
- Windows 版は 2026年7月末に「この秋」の提供を発表、現在は waitlist 経由のベータ配布中
- 料金は無料枠 + Dia Pro（月 20 ドル）の2段構成

## 「目新しくない」のは設計方針どおり

- Arc がパワーユーザー向けだったのに対し、Dia は Chrome / Safari に近い見た目のミニマル設計で一般ユーザーが対象
- Comet や ChatGPT Atlas のような「ブラウザを自律操作するエージェント」路線とは距離を置き、開いているタブを読んで答える・要約する **サイドバーアシスタント** が中核
- 評者からの弱点指摘は「Mac 限定（Apple Silicon 必須）」「ベータの粗さ」「競合よりエージェント機能が弱い」

## 差別化として挙げられている点

- **複数タブの横断参照**: コネクタ不要で、AI 非対応のツールも含め開いているタブをまとめて文脈に入れられる。1 タブ要約なら Chrome 拡張でもできるので、実質的な差はここ
- **Skills**: 定型プロンプトを名前で呼び出す仕組み
- **Dia for Work**: 買収後に企業向けへ再ポジショニング。SSO、MDM（サイト単位で AI を無効化）、Atlassian の Rovo 統合、Gmail / Calendar / Slack / Notion 横断の Morning Brief など

つまり「タブをたくさん開く人向け」というより「複数タブの内容を突き合わせたい人向け」。Jira と仕様書を並べて進捗レポートを書かせる、みたいな用途が想定されている。1〜2 タブしか見ない、調べ物は ChatGPT に直接聞く、という使い方だとほぼ普通の Chromium。

## 内部モデルと制限

- 公式のセキュリティページによると、GPT（OpenAI / Azure）、Claude（Anthropic / Vertex / AWS）、Gemini（Vertex）の複数プロバイダーを束ねている
- どのプロバイダーに回すかは Dia 側の小さなオンデバイスモデルが判断。ユーザーはモデルを選べず、どの質問がどこに行ったかも見えない
- プロンプトと関連ページ内容が各社に送られるが、契約上保持・学習利用はされないとのこと。Dia 自体は既定で一部データを改善用に使う（アカウント非紐付け、30 日で削除、設定でオフ可）
- 無料枠の上限は **数字が公開されていない**。CEO の発言は「週に数回使う程度なら無料のまま」のみ。ユーザー報告では一定回数後にアップグレード案内か応答の遅延
- Pro（月 20 ドル）: チャットと Skills が無制限、パーソナライズされたメモリ、14 日間無料トライアル。将来的に 5 ドル〜数百ドルの複数ティアを用意する意向あり

既に ChatGPT や Claude に月 20 ドル払っている人にとっては、同額でブラックボックスのルーティングを買うことになる。

## 自作するなら

「タブ横断チャット」の核の部分は Chrome 拡張で再現できる。

- `tabs` + `scripting` 権限で各タブに `executeScript` を打って本文を抽出
- 集めたテキストを Claude / OpenAI の API に投げる
- Manifest V3 の `sidePanel` API で表示

週末で動くものにはなる。Dia が独自 Chromium を丸ごとビルドしているのは、UI 全体の統一・MDM 制御・Arc Development Kit の資産といった理由で、この機能単体には不要。

実際に作ると見えてくる、Dia が手間をかけている部分:

- **本文抽出の質**: `innerText` だとナビ・フッター・広告が混ざる。Readability 相当の処理が必要
- **コンテキスト量**: 10 タブで数十万文字になりうる。どのタブを入れるか、圧縮するか、ユーザーに選ばせるかの設計が要る
- **コネクタ層**: Morning Brief やメモリ、Skills 相当は自前で書くか、Claude API の MCP 連携などに頼る
- **コスト**: API 代は自分持ち。ヘビーユースだと月 20 ドルを超えることもある

一方で「モデルを自分で選べる」「何が送られているか分かる」「謎の無料上限がない」という利点はある。まずは本文抽出 + タブ選択チェックボックス + チャットの 3 点だけ作って、Dia と比べて何が足りないかを体感するのが早い。
