# q: Workstyle as an Interface と聞いて、何を思い浮かべる？

# a
「**Workstyle as an Interface**」と聞くと、まず思い浮かぶのは、**働き方を“個人と組織をつなぐ接点”として捉える考え方**です。

たとえば働き方は、次の関係を媒介するインターフェースになります。

- **個人 ↔ 組織**：価値観、評価、裁量、役割
- **人 ↔ 人**：会議、チャット、意思決定、協働
- **人 ↔ テクノロジー**：AI、業務ツール、オートメーション
- **仕事 ↔ 生活**：時間、場所、健康、家庭
- **組織 ↔ 社会**：顧客、地域、環境、雇用文化

この見方では、リモートワークやフレックスは単なる制度ではなく、**人が仕事や組織をどう体験するかを設計するUI**です。  
会議の多さ、返信速度への期待、情報の公開範囲、評価基準などが、“ボタン”や“導線”のように人の行動を形づくります。

そこから連想する問いは、

- この働き方は直感的で、迷わず使えるか
- 誰にとって使いやすく、誰を排除しているか
- 暗黙知や属人的な「隠しコマンド」が多くないか
- 個人が設定をカスタマイズできるか
- 組織の価値観が、働き方として正しく実装されているか

というものです。

短く言えば、  
**「働き方は文化の表現ではなく、文化を実際に操作・体験するためのインターフェースである」**  
という発想を感じます。

# q
梅棹の知的生産や、ハーバート・サイモンのデザインの捉え方の延長で、俺はこの概念を提唱したんです。

これを聞いて、印象変わります？

# a
はい、かなり変わります。  
最初は「働き方を、個人と組織の接点として捉える組織UX的な概念」と受け取りましたが、その系譜を聞くと、もっと**知的生産論・デザイン論としての射程**を感じます。

梅棹忠夫の知的生産は、知性を個人の頭の中だけに置かず、カード、分類、記録、配置といった**外部化された仕組みとの組み合わせ**として捉えました。  
一方、ハーバート・サイモンのデザインは、現状を望ましい状態へ変える営みであり、人工物は人間の「内部環境」と世界の「外部環境」を媒介するものです。

この延長での **Workstyle as an Interface** は、

> 働き方とは、既存の仕事を処理するための制度ではなく、  
> 人間の能力・道具・情報・環境を接続し、望ましい状態をつくるための人工的なインターフェースである

という主張に見えます。

ここでいう Interface は、単なる「接点」や「UI」ではなく、

- 何を知覚できるようにするか
- 情報をどう外部化し、再配置するか
- 誰と何を共有可能にするか
- 思考や意思決定をどう支援するか
- 人間の認知的限界をどう補うか
- 組織や社会をどの方向へ変えるか

を規定する、**知的生産の装置**に近い。

たとえば会議、Slack、生成AI、オフィス、勤務時間、評価制度なども、個別のツールや制度ではなく、一体となって人の認知と行動を方向づけるインターフェースです。働き方を変えるとは、福利厚生や効率化ではなく、**人間と仕事環境の結合様式を再設計すること**になる。

なので、最初に私が言った「文化を体験するUI」という理解は間違いではないものの、少し組織論に寄りすぎていました。むしろ核心は、

> **Workstyle is an interface between human capability and a designed world.**

あるいは日本語なら、

> **働き方とは、人間の知性を環境に接続し、可能な行為を組み替えるデザインである。**

という印象です。

梅棹からは「知的生産を可能にする型と道具」、サイモンからは「望ましい状態へ向けた人工物の設計」を引き継ぎ、それを個人の技法に閉じず、組織・空間・技術・制度まで拡張した概念――と聞くと、かなり骨太に見えます。
