# 全コマンド一覧
公式ドキュメントの全コマンド表を和訳します(引数表記: `<必須>` `[任意]`)。

**A〜R(公式リファレンス表より)**
- `/add-dir <path>` — 現在のセッションにファイルアクセス用の作業ディレクトリを追加
- `/advisor [model|off]` — タスクの要所で第2のモデルに助言を求めるアドバイザー機能のオン/オフ
- `/agents` — サブエージェントの作成・管理(現在はClaudeへの依頼かファイル直接編集を案内)
- `/autofix-pr [prompt]` — CI失敗やレビューコメントに自動で修正をプッシュするWebセッションを起動
- `/background [prompt]` — セッションをバックグラウンド化しターミナルを解放(別名 /bg)
- `/batch <instruction>` — 大規模変更を独立ユニットに分解しworktreeごとに並列実行【スキル】
- `/branch [name]` — 会話をこの時点で分岐して別方向を試す
- `/btw [question]` — 会話履歴に残らないサイド質問をする
- `/bug [report]` — バグ報告・会話の共有(別名 /share)
- `/cd <path>` — セッションを新しい作業ディレクトリへ移動
- `/chrome` — Claude in Chromeの設定
- `/claude-api` — Claude APIのリファレンス資料を読み込む【スキル】
- `/clear [name]` — 空のコンテキストで新しい会話を開始(別名 /reset, /new)
- `/code-review [レベル] [--fix]` — 差分のバグ・改善点をレビューし、--fixで修正適用【スキル】
- `/color [色|default]` — プロンプトバーの色を変更
- `/compact [指示]` — 会話を要約してコンテキストを解放
- `/config [key=value]` — 設定画面を開く/直接設定(別名 /settings)
- `/context [all]` — コンテキスト使用状況をグリッドで可視化
- `/copy [N]` — 直近(またはN番目)の応答をクリップボードにコピー
- `/cost` — /usageの別名
- `/dataviz [依頼]` — グラフ・ダッシュボードのデザイン指針を適用【スキル】
- `/debug [説明]` — デバッグログを有効化し問題を調査【スキル】
- `/deep-research <質問>` — Web検索を並列展開し出典付きレポートを合成【ワークフロー】
- `/design-login` — /design-sync用のアクセス認可
- `/design-sync [名前]` — リポジトリのデザインシステムをClaude Designへアップロード【スキル】
- `/desktop` — セッションをデスクトップアプリで継続(別名 /app)
- `/diff` — 未コミット変更・ターンごとの差分をインタラクティブ表示
- `/doctor` — インストール・設定の診断と修復(別名 /checkup)【スキル】
- `/effort [レベル|auto]` — モデルの推論努力レベルを設定
- `/exit` — CLIを終了(別名 /quit)
- `/export [ファイル名]` — 会話をプレーンテキストで書き出し
- `/fast [on|off]` — 高速モードの切り替え
- `/feedback [内容]` — 製品フィードバックを送信
- `/fewer-permission-prompts` — 読み取り専用コマンドを許可リスト化し確認を削減【スキル】
- `/focus` — 最後のプロンプトと最終応答だけ表示するビューの切り替え
- `/fork [prompt]` — 会話のコピーを新しいバックグラウンドセッションとして起動
- `/goal [条件|clear]` — 条件達成までClaudeが作業し続けるゴールを設定
- `/heapdump` — メモリ診断用ヒープスナップショットを書き出し
- `/help` — ヘルプと利用可能コマンドの一覧を表示
- `/hooks` — フック設定を表示
- `/ide` — IDE統合の管理と状態表示
- `/init` — CLAUDE.mdを生成してプロジェクトを初期化
- `/insights` — セッションの利用パターン分析レポートを生成
- `/install-github-app` — Claude GitHub Appをリポジトリに導入
- `/install-slack-app` — Claude Slackアプリを導入
- `/keybindings` — キーボードショートカット設定ファイルを開く
- `/login` — Anthropicアカウントにサインイン
- `/logout` — サインアウト
- `/loop [間隔] [prompt]` — プロンプトを繰り返し実行(別名 /proactive)【スキル】
- `/mcp` — MCPサーバー接続とOAuth認証を管理
- `/memory` — CLAUDE.md編集と自動メモリの管理
- `/mobile` — モバイルアプリDL用QRコード表示(別名 /ios, /android)
- `/model [モデル]` — モデルを切り替えデフォルトとして保存
- `/passes` — 友人にClaude Code無料1週間をシェア(対象者のみ)
- `/permissions` — ツール権限のallow/ask/denyルール管理(別名 /allowed-tools)
- `/plan [説明]` — プランモードに入る
- `/plugin [サブコマンド]` — プラグインの管理
- `/powerup` — アニメ付きレッスンで機能を学ぶ
- `/pr-comments` — PRコメント表示(v2.1.91で削除済み)
- `/privacy-settings` — プライバシー設定の確認・変更(Pro/Maxのみ)
- `/radio` — Claude FM(ローファイラジオ)をブラウザで再生
- `/recap` — セッションの1行サマリーを生成
- `/release-notes` — 変更履歴をバージョン別に表示
- `/reload-plugins [--force]` — プラグインを再起動なしで再読み込み
- `/reload-skills` — スキル・コマンドディレクトリを再スキャン
- `/remote-control` — claude.aiからこのセッションを遠隔継続可能に(別名 /rc)
- `/remote-env` — クラウドエージェントのデフォルト環境を選択
- `/rename [名前]` — セッション名を変更

**R以降**(表の後半はページ取得が途中で切れたため、同ページの解説部と関連公式ドキュメントから補完しています)
- `/resume` — 過去の会話に戻る(セッションピッカー表示)
- `/review` — GitHub PRの高速な読み取り専用シングルパスレビュー
- `/rewind` — コードと会話をチェックポイントまで巻き戻す
- `/security-review` — 差分のセキュリティ脆弱性をチェック
- `/simplify` — バグ探しではなく再利用・簡素化・効率に絞ったクリーンアップレビューを実行【スキル】
- `/status` — セッション状態を即時表示(応答を中断しない)
- `/subtask` — サイドタスクをサブエージェントに委任し結果をこの会話へ返す
- `/tasks` — セッションのバックグラウンド作業(完了済みサブエージェント含む)を一覧
- `/team-onboarding` — 自分のセットアップをチーム展開用にパッケージ化
- `/teleport` — Web上のセッションをこのターミナルに引き込む
- `/upgrade` — プランのアップグレード(Enterpriseでは非表示)
- `/usage` — 利用量とプラン上限の内訳を表示(別名 /cost)
- `/verify` — 変更内容の検証を実行【スキル】
- `/vim` — プロンプト入力のVimキーバインドを切り替え
- `/workflows` — 動的ワークフローの監視・一時停止・再開・保存

補完部分の正確な原文と最新状況は公式ページ(https://code.claude.com/docs/en/commands)か、セッション内で `/help` を実行して確認するのが確実です。なお、プランや環境によって表示されないコマンドもあります。

# 不足しているコマンド
Gist と公式ドキュメントの両方を確認しました。公式ページ(code.claude.com/docs/en/commands)は私の取得でも表の後半(`/rename` 以降)が途中で切れてしまうため、後半は Claude Code リポジトリの docs 関連 issue に引用された公式表の原文と、公式の個別ドキュメント(statusline / fullscreen / ultraplan / terminal-config 各ページ)で裏取りしました。

**結論:Gist の A〜R 部分は公式表と完全に一致しており、抜けはありません。** 一方、「R以降」の補完部分にはいくつか不足があります。Gist と同じ書式で補うと以下のとおりです。

**不足しているコマンド(S〜W)**

- `/statusline [指示]` — カスタムステータスラインのセットアップをClaudeに依頼する。デフォルトではターミナルのプロンプトを再現しようとし、「モデル名をオレンジで表示」のような追加指示も渡せる
- `/terminal-setup` — Shift+Enterでの改行入力を自動設定するなど、ターミナルのキーバインドを構成する(IDEのターミナル、Warp、Alacrittyなどに対応。Apple Terminalは非対応)
- `/theme` — カラーテーマを変更する
- `/tui [fullscreen]` — ちらつきのないオルタネートスクリーンレンダラー(フルスクリーンモード)に会話を保持したまま切り替える
- `/ultraplan <prompt>` — ultraplanセッションでプランを起案する(クラウドの複数サブエージェントで計画を作り、ブラウザでレビューしてから実行)
- `/web-setup` — ローカルの gh CLI 認証情報を使って GitHub アカウントを Claude Code on the web に接続する

**不足しているエイリアス(既存項目への追記)**

- `/tasks` — 別名 `/bashes` としても利用可能
- `/rewind` — 別名 `/undo`(こちらはサードパーティのまとめ由来の情報で、公式表の原文では未確認です)

**補足・訂正**

- `/ultrareview` は v2.1.111 で単独コマンドとして追加されましたが、現行ドキュメントでは `/code-review ultra` としてクラウドのマルチエージェントレビューを実行する 形に統合されています。Gist の `/code-review` の記載はこの点をカバーできているので問題ありません。
- Gist が補完で挙げている `/resume` `/review` `/rewind` `/security-review` `/simplify` `/status` `/subtask` `/tasks` `/team-onboarding` `/teleport` `/upgrade` `/usage` `/verify` `/vim` `/workflows` は、公式ページの解説部(ワークフロー節)や関連ドキュメントと照合して、いずれも実在を確認できました。この部分に誤りはありません。

なお、表示されるコマンドはプラン・プラットフォーム・バージョンに依存する(例:`/desktop` は macOS/x64 Windows のみ、`/upgrade` は Enterprise では非表示)ため、最終確認はセッション内の `/help` が確実、という Gist 末尾の注意書きはそのまま有効です。#
