# q https://gist.github.com/stakiran/3dc485ffb7f0035256452ac31084a396 広島の事例を見ると、一極集中が難しいことがわかるね。当時広島はまさに集中を避けたくて分散したわけでしょ。その結果、単に不便な「通う場所」になっただけ。

# a
その読みは本質を突いていて、しかも広島の事例は「分散政策の失敗の教科書」として一般化できると思います。いくつか補助線を足します。

**なぜ分散すると「通う場所」にしかならないのか**

集積の経済の中身は、施設ではなく「隣接」そのものです。大学の価値は建物ではなく、学生がバイト先・就職先・遊び場・異分野の人間と歩いて接続できることにある。空港の価値は滑走路ではなく、降りて30分で商談に入れることにある。つまり機能を切り出して遠くに置いた瞬間、その機能の価値の源泉(ネットワークへの隣接)は母都市に置き去りになる。だから移した先は自前の生態系を生まず、母都市の生態系に「通って」寄生するしかない——西条の学生が広島市街まで遊びに出て、本郷の空港へ市内から1時間バスに乗る。あなたの言う「通う場所」は、集積経済の用語で言えば臨界質量未満のノードの必然的な姿です。

**皮肉な入れ子構造**

面白いのは、広島が県内でやったことは、国が東京に対してやろうとしたことの縮小版だという点です。国土の均衡ある発展→筑波・幕張・多摩への機能分散。県土の均衡ある発展→本郷・西条への機能分散。そして結果も同型で、分散先は自立せず衛星化し、核は弱り、**本当の勝者は系の外側にいるより大きな磁石**でした。国レベルでは分散してもなお東京が勝ち、広島県レベルでは分散した結果、弱った広島市ごと東京・大阪・福岡に吸われた。弱い側が内部で分散すると、外部の強者への吸収が加速する——これが広島の事例から引ける一番痛い一般法則だと思います。

**「集中を避ける」こと自体が目標設定の誤り**

対照的に福岡がやったのは分散の逆で、九州内の集中を自分に引き受ける「ミニ東京戦略」でした。東京一極集中への現実的な対抗策は、機能を薄く撒くことではなく、**対抗的な集中を別の場所に作ること**だった。均衡ある発展のイデオロギーは「全員に少しずつ」配って全員が閾値未満になる、という配り方の失敗です。集中は政策で選べる変数ではなく重力に近い現象で、政策が選べるのは「どこに集中させるか」だけ——広島はここを読み違えた、というのがあなたの指摘の精密な言い換えになると思います。

**ただし一つだけ留保**

東広島は完全な失敗ではありません。県内では数少ない人口維持自治体で、旧エルピーダ→マイクロンの半導体工場が立地し、大学発の産業集積が曲がりなりにも芽吹いた。前回の表にも東広島市は登場していません。つまり分散は「40年と幹線交通と製造業なら、ある程度は根付く」。筑波もTX開通後にようやく半自立しました。ただそれは工場と研究者の話であって、広島が失血している22歳の大卒女性が求める都市型の職と暮らしは1ミリも供給しない。**分散が育てられるものと、流出を止めるために必要なものが、そもそも別物だった**——ここが政策目標と手段のミスマッチの核心です。

だから現在の広島駅前再開発や大学の都心回帰は、単なる「昔に戻す」ではなく、50年遅れで「集中は避けるものではなく設計するもの」というパラダイムに乗り換える作業だと言えます。振り子が戻るのに半世紀かかった、というのがこの話の一番重い教訓かもしれません。

# q この現象、名前がついてたりするのかな？それとも新しい視点？

# a
ほぼ全部の歯車に、既存の名前がついています。あなたの視点が新しいのは「組み合わせ方」の方で、部品は経済地理学の古典的概念です。対応表を作るとこうなります。

**「大きい磁石に吸われる」→ 逆流効果(backwash effects)**

グンナー・ミュルダール(1957)の累積的因果関係論。成長する中心は周辺から資本・人材・若者を吸い上げ(逆流効果)、格差は市場に任せると縮まらず拡大する、という理論。「広島が東京・大阪・福岡に吸われる」はこの教科書的事例です。対になる概念が波及効果(spread effects)で、「拠点が育てば周辺に恩恵が滴り落ちる」という期待——後述の通り、日本の国土政策はこちらに賭けて負け続けました。

**「新幹線で1時間だから出やすい・畳まれやすい」→ ストロー効果**

交通インフラの改善が地方を潤すどころか、太いストローで大都市側に吸い上げる現象。日本で瀬戸大橋や新幹線延伸の文脈で定着した用語で、広島のサンドイッチ位置はまさにこれ。学術的には、クルーグマンの新経済地理学(中心・周辺モデル)が「輸送費の低下はある閾値を超えると分散ではなく集積を加速させる」と定式化しており、ストロー効果はその通俗版と言えます。

**「大都市の近くにいると拠点が育たない」→ 集積の陰(agglomeration shadow)**

新経済地理学の用語で、大都市圏の近傍にある中規模都市は、需要も人材も大都市に先取りされて自前の集積を形成しにくい、という現象。対概念がアロンソの「borrowed size(借りた規模)」——大都市の近くの小都市が、大都市の機能を借りて身の丈以上に振る舞える、というポジティブな面。岡山が比較的持ちこたえているのは関西の規模を「借りて」おり、広島は距離が中途半端で「陰」に入っている、と整理できるかもしれません。

**「拠点を作れば地方が発展する」という当時の思想 → 成長の極理論(growth pole theory)とその失敗**

ペルー(F. Perroux)の理論を日本が輸入したのが、全総の「拠点開発方式」、新産業都市、テクノポリス、そして学園都市構想です。広大移転(賀茂学園都市)や本郷空港はこの系譜の末端。そして「拠点を撒いても波及効果は起きず、逆流効果が勝つ」という失敗は、日本の経済地理学・国土政策論で散々検証済みの定番テーマです。あなたの「通う場所になっただけ」は、この文献群で「臨界質量(critical mass)未満の拠点は自立した集積を形成しない」と呼ばれてきたものと同じ診断です。

**「札仙広福が流出を堰き止める」→ ダム機能**

これは国土交通省や地方創生の政策文書で実際に使われている行政用語です。「地方中枢拠点都市のダム機能」で検索すると公文書が出てきます。

**では、新しい部分はどこか**

各部品には名前がありますが、あなたが指摘した**入れ子構造**——「弱い側が内部で均衡発展(分散)をやると、外部のより強い磁石への吸収がかえって加速する」というフラクタル性——を一語で指す確立した名前は、私の知る限りありません。近いのは「国土の均衡ある発展」批判(八田達夫らの都市経済学者による議論、増田レポート以降の「選択と集中」論)ですが、これは主に国レベルの話で、「県が県内でそれを反復し、県ごと沈んだ」という階層をまたいだ相似形として広島を読む視点は、既存概念の新しい適用と言っていいと思います。

ちなみに現行の国土形成計画は「コンパクト+ネットワーク」を掲げていて、これは事実上「均衡ある発展」の敗北宣言です。つまり国の公式見解も50年かけてあなたと同じ結論に着地した——ただし名前をつけたのは、失敗が出揃った後でした。
