# テックセールスとその周辺職種の整理

「テックセールス」「カスタマーサクセス」「プリセールス」「ソリューションアーキテクト」「FDE」——似たような文脈で登場するこれらの職種は、それぞれ切り口の違う言葉です。本稿では、混同されがちなこれらの用語を整理します。

## テックセールスとは

テックセールスとは、ITやテクノロジー系企業(SaaS企業、クラウドベンダー、ソフトウェア会社など)で法人向けに自社製品を販売する営業職の総称です。単にモノを売るのではなく、顧客の課題をヒアリングし、自社のテクノロジーでどう解決できるかを提案するコンサルティング型の営業スタイルが特徴です。

近年この言葉をよく聞くようになった背景には、次のような事情があります。

- **SaaS市場の急成長**: 企業のDX需要の高まりを受け、国内外のSaaS企業が営業人材を大量に採用してきた。サブスクリプション型ビジネスでは顧客と継続的な関係を築ける営業が事業の生命線となる。
- **給与水準の高さ**: 外資系テック企業のセールスは成果次第で高年収が狙えるため、転職メディアやSNSで頻繁に取り上げられる。
- **転職市場の活況**: 営業経験があればIT未経験でも挑戦しやすく、人材紹介会社やスクールが「テックセールス」という言葉を積極的に使って露出が増えている。
- **SIerなどIT業界内の営業変革**: 受託開発中心の「モノ売り」から、クラウドやサブスク型商材を提案する「コト売り」への転換が進み、新しい営業像を指す言葉として使われるようになった。

## 前提: 営業の分業体制「The Model」

テック業界の営業は、米国SaaS企業発祥の「The Model」と呼ばれる分業体制を採ることが一般的です。顧客ジャーニーの段階ごとに担当が分かれます。

| 段階 | 職種 | 役割 |
|------|------|------|
| 商談前 | インサイドセールス (SDR/BDR) | 見込み顧客にアプローチし、商談を創出する |
| 商談〜契約 | フィールドセールス (AE) | 商談を主導し、契約まで持っていく |
| 契約後 | カスタマーサクセス (CS) | 製品活用を支援し、解約防止・追加契約につなげる |

## 各職種の整理

### カスタマーサクセス (CS)

**「担当する時間軸」で定義される職種**です。契約後の顧客だけを担当し、製品を使いこなしてもらって解約を防ぎ、アップセルにつなげることがミッションです。サブスク型ビジネスでは契約後の継続が売上の大半を占めるため、営業の一種でありながら「売る」より「顧客を成功させる」ことが評価軸になります。

### プリセールス

**「役割の性質」で定義される職種**です。商談段階に関わる点ではフィールドセールスと同じですが、営業本人ではなく技術の専門家として同行する立場です。デモの実施、技術的な質問への回答、導入検証(PoC)の支援などを担当し、多くの場合、個人の売上目標(数字)は持ちません。セールスエンジニアと呼ばれることもあります。

### ソリューションアーキテクト (SA)

プリセールスの発展形・上位形と考えるとわかりやすい職種です。AWS、Google Cloud、Microsoftといったクラウドベンダーで広く使われています。単発の商談でデモや技術説明をするだけでなく、**顧客のシステム全体のアーキテクチャ設計に責任を持ち**、契約後も設計レビューや技術ガイダンスで顧客に伴走します。プリセールスより関与が深く、長いのが特徴です。個人の売上目標は持たないのが普通ですが、担当顧客のクラウド利用額拡大が間接的な評価指標になることはあります。

### FDE (Forward Deployed Engineer)

この中では最も新しい概念です。Palantirが有名にした職種で、近年OpenAIやAnthropicといったAI企業が採用を拡大したことで注目度が上がりました。直訳すると「前線配備エンジニア」。その名の通り顧客の現場に深く入り込み、**自社製品を顧客の環境や業務に合わせて実装・カスタマイズし、実際に動く形にして価値を出すところまで**を担います。

プリセールスやSAとの決定的な違いは、提案や設計図で終わらず、自分でコードを書いて成果物を作る点です。一方で、社内で製品そのものを開発するエンジニアとも異なり、顧客と直接向き合い、成果が契約の拡大や継続に直結するため、「営業と開発の中間」とよく表現されます。生成AIのように、導入しただけでは価値が出ず、顧客の業務に組み込んで初めて成果が出る製品では、FDEの重要性が急上昇しています。

## 全体像: 3つの切り口

これらの用語が重なって聞こえるのは、それぞれ定義の切り口が違うからです。

- **テックセールス**: 業界を指す「傘」となる総称
- **カスタマーサクセス**: 契約後という「段階」を指す言葉
- **プリセールス / SA / FDE**: 技術支援という「機能」を指す言葉

営業寄り〜技術寄りのスペクトラムで並べると、次のようになります。

```
営業寄り ◀──────────────────────────────▶ 技術寄り

フィールドセールス → プリセールス → SA → FDE → (開発エンジニア)
   数字を持つ営業      商談の技術支援   設計に責任  実装まで担う   製品を作る側
```

## 求人・職種名を見るときのポイント

「テックセールス」という言葉の定義は会社ごとにかなり異なります。同じ名前でも、実態が「ほぼ新規開拓営業」の場合と「ほぼプリセールスエンジニア」の場合があり、求められるスキルも評価のされ方も大きく変わります。

見分ける最も簡単なサインは、**募集要項に「売上目標」「ノルマ」「クォータ」という言葉があるかどうか**です。あれば数字を持つ営業職、なければ技術支援側の職種である可能性が高いでしょう。

また、技術支援系の職種(プリセールス / SA / FDE)はエンジニア経験との親和性が高く、要件定義や顧客折衝が得意ならSA寄り、手を動かして作るのが好きならFDE寄り、という向き不向きの分かれ方をします。エンジニアからのキャリアチェンジを考える場合、営業への転身というよりエンジニアとしてのキャリアの延長線として捉えられる職種です。
