## Claude Code CLI オプション一覧(日本語)

**基本**
- `prompt` — プロンプト(引数)
- `-p, --print` — 応答を出力して終了(非対話モード)
- `-v, --version` — バージョン表示
- `-h, --help` — ヘルプ表示

**セッション管理**
- `-c, --continue` — 現在のディレクトリで直近の会話を続行
- `-r, --resume [値]` — セッションIDで再開、または対話式ピッカーを開く
- `--fork-session` — 再開時に元のIDを使わず新しいセッションIDを作成
- `--session-id <uuid>` — 特定のセッションIDを指定
- `-n, --name <名前>` — セッションに表示名を設定
- `--from-pr [値]` — PR番号/URLに紐づくセッションを再開
- `--no-session-persistence` — セッションをディスクに保存しない(--print専用)
- `--bg, --background` — バックグラウンドエージェントとして起動し即座に戻る

**モデル・動作設定**
- `--model <モデル>` — セッションで使うモデルを指定(fable、opus、sonnet など)
- `--fallback-model <モデル>` — 過負荷時のフォールバックモデルを指定(--print専用)
- `--effort <レベル>` — 努力レベル(low〜max)を指定
- `--autocompact <auto|トークン数>` — 自動コンパクトのウィンドウサイズ
- `--betas <ベータ...>` — APIリクエストに含めるベータヘッダー(APIキー利用者のみ)
- `--max-budget-usd <金額>` — API呼び出しの上限金額(--print専用)

**権限**
- `--permission-mode <モード>` — 権限モード(acceptEdits、plan など)
- `--dangerously-skip-permissions` — 全権限チェックをバイパス(隔離環境推奨)
- `--allow-dangerously-skip-permissions` — バイパスをオプションとして有効化(デフォルトでは無効)
- `--allowedTools <ツール...>` — 許可するツールのリスト
- `--disallowedTools <ツール...>` — 拒否するツールのリスト
- `--tools <ツール...>` — 利用可能な組み込みツールを指定

**プロンプト・エージェント**
- `--system-prompt <プロンプト>` — システムプロンプトを置き換え
- `--append-system-prompt <プロンプト>` — デフォルトのシステムプロンプトに追記
- `--agent <エージェント>` — セッションのエージェントを指定
- `--agents <json>` — カスタムエージェントをJSONで定義
- `--exclude-dynamic-system-prompt-sections` — マシン固有情報を最初のユーザーメッセージへ移動(キャッシュ再利用向上)

**入出力(主に --print 用)**
- `--output-format <形式>` — 出力形式(text、json、stream-json)
- `--input-format <形式>` — 入力形式(text、stream-json)
- `--json-schema <スキーマ>` — 構造化出力のJSONスキーマ検証
- `--include-partial-messages` — 部分メッセージチャンクを含める
- `--include-hook-events` — フックのライフサイクルイベントを出力に含める
- `--replay-user-messages` — stdinのユーザーメッセージをstdoutに再送出
- `--forward-subagent-text` — サブエージェントのテキストを転送
- `--prompt-suggestions [値]` — 次のプロンプト候補の提案を有効化

**環境・ファイル**
- `--add-dir <ディレクトリ...>` — ツールアクセスを許可する追加ディレクトリ
- `--file <指定...>` — 起動時にダウンロードするファイルリソース
- `-w, --worktree [名前]` — セッション用に新しいgitワークツリーを作成
- `--tmux` — ワークツリー用のtmuxセッションを作成(--worktree必須)

**設定・プラグイン・MCP**
- `--settings <ファイル|JSON>` — 追加設定を読み込む
- `--setting-sources <ソース>` — 読み込む設定ソース(user、project、local)
- `--mcp-config <設定...>` — JSONファイル/文字列からMCPサーバーを読み込み
- `--strict-mcp-config` — --mcp-config指定のMCPサーバーのみ使用
- `--plugin-dir <パス>` — ディレクトリ/.zipからプラグインを一時読み込み(繰り返し可)
- `--plugin-url <URL>` — URLからプラグイン.zipを一時取得(繰り返し可)
- `--disable-slash-commands` — 全スキルを無効化

**特殊モード**
- `--bare` — 最小モード(フック、プラグイン同期、自動メモリ等をスキップ)
- `--safe-mode` — 全カスタマイズを無効にして起動(設定トラブル調査用)
- `--brief` — SendUserMessageツールを有効化(エージェント→ユーザー通信用)
- `--remote-control [名前]` — リモートコントロール有効で対話セッション開始
- `--remote-control-session-name-prefix <接頭辞>` — 自動生成セッション名の接頭辞
- `--chrome` / `--no-chrome` — Chrome連携の有効化/無効化
- `--ide` — 起動時にIDEへ自動接続
- `--ax-screen-reader` — スクリーンリーダー向け出力

**デバッグ**
- `-d, --debug [フィルタ]` — デバッグモード(カテゴリフィルタ可)
- `--debug-file <パス>` — デバッグログを指定ファイルに書き出し
- `--verbose` — 詳細モードを設定より優先して有効化

**サブコマンド**
- `agents` — バックグラウンドエージェント管理
- `auth` — 認証管理
- `auto-mode` — 自動モード分類器の確認/リセット
- `doctor` — インストールの健全性チェック
- `gateway` — エンタープライズ認証/テレメトリゲートウェイ
- `install` — ネイティブビルドのインストール
- `mcp` — MCPサーバーの設定・管理
- `plugin` — プラグイン管理
- `project` — プロジェクト状態の管理
- `setup-token` — 長期認証トークンの設定(サブスク必須)
- `ultrareview` — クラウド上でのマルチエージェントコードレビュー
- `update` — アップデート確認とインストール
