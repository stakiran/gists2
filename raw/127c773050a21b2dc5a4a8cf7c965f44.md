# ニコニコ的「創作生態系」は今も存在するか、再現するには何を出すべきか

2026年9月時点の整理。

## 1. 問い

ニコニコ動画が2000年代後半に持っていた「匿名の個人が起点になり、作品が作品を呼び、その場で新ジャンルが生まれる」生態系は、今の日本にまだあるのか。無いなら、再び生むには何を出せばよいか。

## 2. 現状調査（4視点）

### 2-1. 場の規模（悲観派の視点）

- プレミアム会員数：2026年6月末で89.3万人。初の90万人割れ。ピークは250万人。
- 年間アクティブユーザー：全盛期868万人 → 2024年455万人（ほぼ半減）。
- 2024年6月のサイバー攻撃で長期停止、その後復旧。
- 2024年10月から海外アクセス制限を開始。
- 2026年8月にプレミアム790円→990円へ値上げ。
- 一方、Webサービスセグメントの収益は堅調で、超会議来場者・協賛売上は増加。「小さくまとまった村」として存続可能な体制。

結論：広場としては明確に縮小した。

### 2-2. 生態系の回転（ボカロ圏の視点）

- ボカコレ2026夏（8/20–24）：5日間で投稿7,200件以上、生放送来場者約25万人。
- 部門設計：TOP100 / ルーキー（活動2年以内限定）/ REMIX（既存曲の再構築）。新規参入枠と派生枠が制度化されている。
- 有名P 54名がStemデータを提供。「有名が素材を放出し、無名が派生を作る」回路が運営主導で回っている。
- 2020年代に入っても新規ボカロPの参入が続いている。

結論：「作品が作品を呼ぶ」回路は、年2回の祭り形式でニコニコ上に現存する。

### 2-3. ツール起点の文化発生（技術屋の視点）

- VOICEVOX（2021年、個人開発、無償・商用可）→ ずんだもんが動画文化の共通素材化。
- ガイドライン：非商用二次創作は申請不要。切り出し・色変更・服装変更・他キャラとのタイアップ・3Dモデルの改造再配布まで許可。
- MMD / VRM / VRChatアバターを公式配布。
- 『ずんだホライずん』続編クラファンで第10ゴール（5,700万円）「あんこもんのVOICEVOX対応」が達成され、2026年1月に新キャラがリリース。
- 2026年8月にVOICEVOX 5周年。

結論：「ツール＋キャラ＋開放ライセンス」が文化を生む構造は、2020年代に再度成立した。初音ミク型の再現例。

### 2-4. 連鎖の速度と出自（ミーム観察者の視点）

- 「スピキ」：韓国ゲームのキャラ音声 → 2025年末から日本のTikTok/YouTubeで拡散 → ニコニコ・XでMAD/コラ大量発生 → 2026年1月に公式が授賞式を開催。
- 「格付けミーム」：中国・深センのクリエイターのアニメ動画が元ネタ → 2025年にXで日本で爆発 → 継続的に二次創作。
- 生成AIで既存ミームを「動かす」派生が主流化。人間のネタをAIが補強し、AI生成物を人間がネタ化する循環。

結論：派生連鎖自体は活発。ただし起点は国境をまたぎ、「日本発・日本の広場に閉じる」条件は外れている。

## 3. 総合判断

- 「生態系は消滅した」は誤り。ボカコレ圏とVOICEVOX圏で現役。
- ただし規模はピークの半分以下で、ニコニコ単独ではなくYouTube・X・TikTokをまたぐ分散型。
- 単一の場が無いため、「深夜の無名投稿が翌朝に全国区」という爆発力は弱い。
- 新ジャンルの起点が国際化し、「日本固有」という枠自体が薄れている。

## 4. 生態系が回るための5条件

1. **共通の楽器**：安く使え、派生を法的に許すもの（ミク＋ピアプロ、VOICEVOX）。
2. **派生が正当な作品として扱われる仕組み**：コンテンツツリーと、ツリーに沿った収益還元。YouTube/TikTokのアルゴリズムは視聴維持率を報酬にし、系譜を評価しない。現在最も欠けている条件。
3. **見ることが参加になる回路**：弾幕コメント、タグ。視聴者の命名が次の作品の題材になる。
4. **共通の時間**：全員が同時に同じ場にいること。常設の場より「祭り」が今は機能する（ボカコレが証拠）。
5. **新人の枠**：ルーキー部門のように、無名が別枠で可視化される設計。

## 5. 出すべきもの（優先順）

### 5-1. 開放ライセンスの「素材」（最優先）

- 個人でも出せる。VOICEVOXは個人開発者の無償公開から5年で5,700万円のクラファンに至った。
- 今出すなら「制約」を売る。生成AIで誰でも何でも作れる時代には、「この声・この顔でしか作れない」という共通の縛りが希少になる。
- 要件：
  - 声・立ち絵・3D・設定をセットで、商用含め改変再配布自由。
  - 公式は「正典」を作らない。性格も物語も投稿者に委ねる（ミク成功の最大要因）。
  - 生成AIモデルへの学習利用を明示的に許可する。禁止すると2026年の派生の主戦場から外れる。

### 5-2. 系譜を報酬化する仕組み

- 既存プラットフォームの上に乗る外部DB：「この作品の元ネタはこれ」を登録し、派生数に応じて親作品に投げ銭を分配。
- 有名クリエイターが素材を放出する動機を生む（ボカコレのStem提供を、運営の人力ではなく仕組みで行う）。

### 5-3. 定期の祭り

- 素材を出した人が自ら主催。年2回、素材縛りの投稿祭。ルーキー枠とリミックス枠つき。
- 会場は借り物でよい（ニコニコでもYouTubeでも可）。

### 出しても意味がないもの

- 新しい動画プラットフォーム：ユーザーをさらに分散させるだけ。
- 公式が世界観を作り込んだキャラ：ファンが動かす余地が無い。
- 「日本発」にこだわった閉じた場：派生連鎖は国境をまたぐ。海外を締め出したニコニコはそれで選択肢を失った。

要約：再現すべきは「広場」ではなく「楽器と祭り」。

## 6. どんな楽器をつくるか

### 見当をつける型

過去に成功した楽器はすべて「素人にできなかった工程を一つ潰し、それに顔を付けた」もの。

| 工程のボトルネック | 楽器 |
|---|---|
| 歌が歌えない | 初音ミク（歌唱＋顔） |
| 声優が呼べない | ゆっくり、ずんだもん（読み上げ＋顔） |
| 踊れない、モデルが作れない | MMD＋配布モデル |
| 楽曲の権利処理ができない | ピアプロのオフボーカル配布 |

ツールだけでは派生が散る。顔があると派生が一人のキャラに集積する。ミクの本質は歌唱ソフトではなく「派生の受け皿になる人格」。

探すべきは「2026年の素人がまだできない工程」×「まだ顔が付いていない技術」の交点。

### 候補

1. **生成動画の顔**：同じキャラを一貫して動かすことが素人には未だ困難。声・容姿・動き・画風をセットで、AI学習・出力に使ってよいと明記したキャラを出す。公式が用意するのは重み（LoRA、音声モデル、3Dモデル）と設定の空白だけ。
2. **一人バンド**：癖のあるAI演奏キャラ（ドラマー、ベーシスト）を開放ライセンスで出す。「あのドラマーに叩かせた曲」というタグが生まれ、演奏者としての人気がキャラに集積する。ボカロ圏に接木しやすい。
3. **演技の素材庫**：振り付けや芝居のモーションをキャラの癖ごと配布。「演技ってみた」を可能にする。MMDの後継、VRChat圏と接続。
4. **主人公のいないゲームキット**：共通の主人公と空白の世界観、無償ツール。誰もが同じ主人公の別の物語を作る。ゲームは派生先として未開拓。
5. **開放された会話人格**：ローカルで動く、性格の芯だけ決めたキャラモデル。派生対象が「作品」から「その子とのやりとり」になる。最も新しく最も危うい。

### 一つ選ぶなら：1（生成動画の顔）

- 素人の最大のボトルネックを突いている。
- 生成AIという既存の道具に顔がまだ無い。
- 他キャラがAI利用を禁止する方向に動いており、「許可」で埋めるだけで差別化できる逆張りの空きがある。

### 作る前の検証法

楽器を作り込む前に、素材を一つだけ出す。声のサンプル、立ち絵一枚、「改変・学習・商用すべて自由」の一文。一ヶ月、こちらから仕掛けずに待つ。誰かが勝手に何かを作ったら、そこが楽器の正体。

ずんだもんは公式が育てたのではなく、勝手に動画にされたことで楽器になった。見当は考えて付けるものではなく、最初の一本を投げて観察するもの。
